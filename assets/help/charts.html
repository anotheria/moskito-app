Charts Help

Each view in the configuration of a View can contain charts. As opposed to the charts that you can directly open from component info dialog, those charts usually refer to multiple components, for example multiple instances for of same application.

For example the DEMO application, which is a burgershop running on 3 locations, will presents orders from each location on one chart, tomcat sessions on another, CPU load and AVG URL response time.

Charts are configured in the instance of the MoSKito Control you are connecting to.

Here is an example chart showing the number of sessions on different instances


On top of each chart there is a small control line with the name of the chart and the i-button. The i-button opens the chart info dialog, which shows the names and colours of the individual lines.

Clicking on the (i) will show you the names of the lines in the chart and their colours.
