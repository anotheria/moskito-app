Settings Help

MoSKito connects to MoSKito-Control instance(s) to retrieve information about component health, charts, and history. The systems MoSKito can connect to are configured under Settings.

When you first start the app, or if you delete all system entries, the DEMO system will appear to help you understand how the app works. You can delete the DEMO system entry once you have added your own instances.

To add a new system, tap the Add System button at the bottom of the screen. You will be asked for the system's name and URL. The URL should typically start with http or https and end with /api/v2. For example, the URL for the DEMO system is:

https://burgershop-control.demo.moskito.org/api/v2

Learn more about MoSKito on the MoSKito Homepage or check out the GitHub Project.
