History

The **History** tab displays all past status changes of the system's components.

Upon opening the tab, you will see the history for all components and views within the system.

You can select a different view using the **selection tab** located at the top of the page.

Tapping on any row will open a dialog with detailed information about the selected alert.

Learn more about MoSKito on the MoSKito Homepage or explore the GitHub Project.
