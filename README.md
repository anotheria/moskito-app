# MoSKito Monitoring App

**MoSKito Monitoring** is your mobile companion for real-time performance monitoring of Java-based systems. Seamlessly connect to multiple **MoSKito-Control** instances and stay informed about the health and performance of your applications—anytime, anywhere.

## 🚀 Key Features

### Real-Time Monitoring
Instantly access performance data like CPU and memory usage, request durations, and component statuses across multiple systems.
### Comprehensive System Views
Organized insights with customizable views (e.g., Frontend, Backend, End-to-End Processes) for a clear overview of system health.
### Detailed Component Analysis
Dive deep into individual components to view thresholds, charts, and detailed information for accurate issue tracking.
### Interactive Alert History
Review historical status changes and alerts to identify patterns and improve system reliability.
### Multi-Instance Connectivity
Effortlessly connect to multiple MoSKito-Control instances for centralized monitoring of complex infrastructures.
### Intuitive UI
Designed for quick navigation and real-time decision-making, ensuring critical issues are always in focus.

## 🔒 Why MoSKito Monitoring?
	- Stay proactive: Receive instant insights into system health.
	- Boost productivity: Access critical data on the go.
	- Enhance reliability: Quickly detect and address performance issues.
